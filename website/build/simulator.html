Simulator

This simulator searches for a short route through every McDonald’s in Manhattan using simulated annealing. The route ends at 160 Broadway. Arriving at a closed restaurant means waiting for it to open.

Start date and time determine which restaurants are open when. Pace converts walking distance to time. Seed fixes the random choices, so the same inputs give the same result. Changes apply on restart. The result is one possible route, not a recommended or official one. See Route.

Questions and new results: admin@mctrot.nyc.
